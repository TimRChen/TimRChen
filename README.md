### 🎮 Mods & Localization

**TABCheats** — in-game cheat/utility mod for *They Are Billions*. It hooks the game through **TABModLoader + Harmony**, so it plays nicely alongside **TABHelper**; the cheat itself stays **off by default** until you turn it on.

What shipped across `v1.0.2` → `v1.0.6`:

- 🎚️ fixed the unusable **game-speed slider** and the wrong speed-patch target
- 🏗️ **instant build** — by compressing build time instead of faking `BuildingFactor`
- 📦 **unlimited production** (real output, not just stock on hand)
- ⏱️ capped **research / training duration**
- 🔒 **off by default**, and says so — a mod that doesn't quietly change your save
